# Журкин · Рейсы — Android-приложение

Учёт рейсов на Газели: оплата, траты по категориям, налог НПД, износ и чистая прибыль.
Все записи хранятся только на телефоне.

## Как получить APK без Android Studio (через GitHub, бесплатно)

1. Зарегистрируйтесь на https://github.com (если ещё нет аккаунта).
2. Нажмите «+» → **New repository**, назовите `zhurkin-app`, нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите туда
   всё содержимое этой папки (вместе со скрытой папкой `.github`). Нажмите **Commit changes**.
   Если `.github` не перетаскивается: **Add file → Create new file**, имя
   `.github/workflows/build-apk.yml`, и вставьте текст из этого файла.
4. Откройте вкладку **Actions**. Сборка запустится сама (около 5 минут).
5. Когда появится зелёная галочка, откройте сборку и скачайте **Zhurkin-Reisy-APK**
   внизу страницы. Внутри архива файл `Zhurkin-Reisy.apk`.
6. Перекиньте APK на телефон и установите. Android попросит разрешить установку
   из этого источника.

## Через Android Studio

Откройте папку как проект → Build → Build App Bundle(s) / APK(s) → Build APK(s).

## Важно про данные

Записи лежат во внутренней памяти приложения. Если удалить приложение или очистить
его данные, записи пропадут.
